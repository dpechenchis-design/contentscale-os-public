# hormozi-leads — стратегічний фреймворк "$100M Leads" від Alex Hormozi

Повна система лідогенерації: від першого теплого аутрічу до $100M+ машини.
НЕ плутати з `hormozi-shortform` (там скрипти відео за Hook/Retain/Reward). Цей скіл =
бізнес-стратегія залучення клієнтів, а не контент-формат.

## Референс
- **framework.md** — повний витяг з книги: всі 5 секцій, формули, матриці, покрокові процеси,
  7-рівневий roadmap, mental models.

## Ядро системи

### Premise
Ти не отримуєш достатньо лідів, бо недостатньо рекламуєш. Реклама завжди працює;
питання лише в ефективності.

### Value Equation
**(Dream Outcome x Perceived Likelihood) / (Time Delay x Effort & Sacrifice)**
Застосовується до КОЖНОГО offer/lead magnet/affiliate пропозиції. Чим вищий чисельник і
нижчий знаменник — тим ціннішою здається пропозиція.

### Core Four (4 способи повідомити людям про те, що продаєш)

|               | WARM (знають тебе)   | COLD (незнайомці)    |
|---------------|----------------------|----------------------|
| **1-to-1**    | #1 Warm Outreach     | #3 Cold Outreach     |
| **1-to-Many** | #2 Post Free Content | #4 Run Paid Ads      |

### Lead Magnets
Безкоштовне повне рішення вузької проблеми → розкриває ширшу проблему → core offer вирішує ширшу.
- 3 типи: Reveal Problem / Samples & Trials / One Step of Multi-Step
- 4 механізми доставки: Software / Information / Services / Physical Products
- 7 кроків створення (деталі у framework.md)

### More Better New (масштабування Core Four)
1. **MORE** — роби більше поки не "зламається" (diminishing returns)
2. **BETTER** — знайди constraint, виправ, знову MORE
3. **NEW** — нові placements → нові платформи → новий Core Four метод

### 4 типи Lead Getters (люди, що приводять лідів ЗА тебе)
1. **Customer Referrals** — Referral Growth Equation + 6 способів давати більше цінності + 7 способів просити
2. **Employees** — 3D Training (Document/Demonstrate/Duplicate) + Internal Core Four для найму
3. **Agencies** — використовуй для НАВЧАННЯ, не аутсорсу; Agreement Framework на 6 місяців
4. **Affiliates** — 6-кроковий процес побудови армії; Whisper-Tease-Shout запуск; 3 методи інтеграції

### Rule of 100 & Open To Goal
- **Rule of 100:** 100 основних дій/день x 100 днів (100 аутрічів АБО 100 хв контенту АБО $100 на рекламу)
- **Open To Goal:** не кількість дій, а кількість РЕЗУЛЬТАТІВ. Працюй поки не досягнеш цілі, байдуже скільки часу

### 7-Level Roadmap (0 → $100M+)
1. Друзі знають що продаєш → Warm outreach
2. Послідовно всім розказуєш → Warm + Content
3. Наймаєш людей для реклами → Employees
4. Продукт дає 25%+ referrals → Product + Referral program
5. Багато методів на багатьох платформах → Multi-method multi-platform
6. Наймаєш керівників під канали → Executives
7. (TBD)

## Ключові формули

| Формула | Значення |
|---------|----------|
| **LTGP:CAC** | Lifetime Gross Profit : Customer Acquisition Cost (мінімум 3:1) |
| **Referral Growth** | % Referred/mo - % Churned/mo = % Compounding Growth |
| **Goodwill** | Value - Price = Goodwill → word of mouth |
| **Content Unit** | Hook + Retain + Reward |
| **Ad Content** | Call Out + Value + CTA |
| **Affiliate LTGP:CAC** | Gross profit від ВСІХ клієнтів affiliate / Cost to acquire affiliate |

## Режими використання

### 1. Діагностика рівня клієнта
**Вхід:** опис бізнесу клієнта (ніша, виручка, як зараз залучають клієнтів, розмір команди).
**Процес:**
1. Визнач рівень на 7-Level Roadmap
2. Визнач які Core Four вже використовуються і на якому етапі (More/Better/New)
3. Визнач які Lead Getters активні
4. Покажи GAP: що мав би робити на цьому рівні vs що робить зараз
**Вихід:** діагностична карта + 3 конкретні дії для переходу на наступний рівень

### 2. Lead Magnet конструктор
**Вхід:** core offer клієнта + ніша + аватар.
**Процес:**
1. Визнач вузьку проблему аватара (яку core offer вирішує ширше)
2. Обери тип lead magnet (Reveal / Samples / One Step)
3. Обери механізм доставки (Software / Info / Services / Physical)
4. Прогони через Value Equation (макс Dream Outcome + Likelihood, мін Time + Effort)
5. Назви compelling (обіцянка + специфіка)
**Вихід:** готовий lead magnet brief з CTA ланцюжком до core offer

### 3. Referral система
**Вхід:** продукт клієнта, поточний churn %, поточний referral %.
**Процес:**
1. Порахуй Referral Growth Equation → покажи де клієнт (зростає/flat/падає)
2. Пройди 6 способів давати більше цінності через Value Equation
3. Обери 2-3 з 7 способів просити referrals, що підходять до бізнес-моделі
4. Побудуй Referral Action Plan
**Вихід:** referral план з метриками + incentive структура

### 4. Affiliate Army план
**Вхід:** core offer + ідеальний профіль affiliate.
**Процес:**
1. Step 1: Find ideal affiliate (що купують їхні клієнти? де ходять?)
2. Step 2: Make offer через Value Equation
3. Step 3: Qualify (customer або expert path)
4. Step 4: 3-tier payout structure на основі max CAC
5. Step 5: Whisper-Tease-Shout launch план з таймлайном
6. Step 6: Integration method (give away / sell lead magnet / sell core offer)
**Вихід:** повний affiliate launch playbook

### 5. One Page Advertising Checklist
**Вхід:** тип engaged lead (Customers/Affiliates/Employees/Agencies) + Core Four метод.
**Процес:** заповни Advertising Daily Checklist:
- Who / What / Where / To Whom / When / Why / How / How Much / How Many / How Long
**Вихід:** заповнений чекліст + Rule of 100 або Open To Goal commitment

### 6. Cold Outreach план
**Вхід:** продукт + цільова аудиторія.
**Процес:**
1. Build a List (який метод: software/manual/agency)
2. Personalize + Big Fast Value (що дати безкоштовно одразу)
3. Volume plan (хто робить: ти/VA/software/combo)
4. Benchmarks для обраного каналу (phone/email/DM)
**Вихід:** план холодного аутрічу з очікуваними конверсіями

### 7. Paid Ads фреймворк
**Вхід:** продукт + бюджет + платформа.
**Процес:**
1. Ad Content: Call Out (Label/Yes-Q/If-Then/Ridiculous Results) + Value + CTA
2. Nonverbal: Contrast/Likeness/Mascots
3. Math: порахуй target LTGP:CAC, max allowable CAC
4. Testing plan: що тестувати першим (offer > audience > creative)
5. Scaling: коли збільшувати бюджет (LTGP:CAC > 3:1)
**Вихід:** 3-5 ad concepts + тестова матриця + scaling triggers

## Non-negotiables
- **Value Equation** — застосовуй до БУДЬ-ЯКОЇ пропозиції (lead magnet, affiliate offer, ad, referral incentive)
- **LTGP:CAC мінімум 3:1** — нижче = не масштабуй, покращуй спочатку
- **Rule of 100 = мінімум** — якщо клієнт робить менше 100 дій/день, проблема = volume, а не стратегія
- **Agencies = навчання** — ніколи не рекомендуй аутсорсити лідогенерацію назавжди; завжди план повернення in-house
- **Порядок масштабування** — завжди MORE перед BETTER, BETTER перед NEW
- **Diagnostic question** — "Чи мають мої engaged leads проблему яку я вирішую І гроші щоб заплатити?"
  Ні = проблема реклами. Так але не купують = проблема продажів.
