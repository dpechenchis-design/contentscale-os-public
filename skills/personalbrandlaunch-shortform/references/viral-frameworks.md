# Viral Frameworks Reference (100 Reels Analysis)

Complete framework ranking and visual format guide for PersonalBrandLaunch (Ava) shortform content, based on analysis of 100 Instagram reels.

---

## TOP 10 FRAMEWORKS BY AVERAGE VIEWS

### #1. RESOURCE / TOOLKIT GIVEAWAY
- **Avg views:** 2.4M | **Reels analyzed:** 2
- **Top reel:** 3,309,672 views (sound effects)
- **Structure:**
  - List specific categorized resources (sound effects, songs, tools)
  - End with comment CTA ("I can send these over")
  - The video itself is a curated resource library, not education
- **Why viral:** Triggers save-and-share reflex, immediate tangible value

### #2. MY STORY / REINTRODUCTION
- **Avg views:** 679K | **Reels analyzed:** 1
- **Top reel:** 678,962 views
- **Structure:**
  - Identity markers + chronological life story
  - Vulnerability + unexpected details (ADHD, engaged at 16)
  - Forward-looking vision + follow CTA

### #3. "I ASK AI TO..." WORKFLOW LIST
- **Avg views:** 191K | **Reels analyzed:** 2
- **Top reel:** 294,394 views
- **Structure:**
  - "I ask AI to [specific task]" repeated structure
  - Covers 4-6 use cases in rapid succession

### #4. WEEKLY SCHEDULE SHOWCASE
- **Avg views:** 180K | **Reels analyzed:** 2
- **Top reel:** 248,720 views
- **Structure:**
  - Monday-through-Sunday visual content schedule
  - Minimal narration, visual does the work

### #5. CLONE / DIALOGUE FORMAT
- **Avg views:** 144K | **Reels analyzed:** 3
- **Top reel:** 267,712 views
- **Structure:**
  - Two versions of Ava have a conversation
  - Q&A back-and-forth with reactions ("Wait, really?")
- **Note:** Ava herself called this "the format most likely to go viral"

### #6. HYPOTHETICAL CHALLENGE
- **Avg views:** 140K | **Reels analyzed:** 6
- **Top reel:** 443,518 views
- **Structure:**
  - "If I had to [achieve X] in [Y time], here's how"
  - Step-by-step breakdown with constraint

### #7. GOOD/BETTER/BEST TIERED SCALE
- **Avg views:** 106K | **Reels analyzed:** 3
- **Top reel:** 122,792 views
- **Structure:**
  - Bad/100 views -> Good/100K views -> Great/1M views
  - Real examples at each tier

### #8. SAME PATTERN, DIFFERENT EXAMPLES
- **Avg views:** 100K | **Reels analyzed:** 6
- **Top reel:** 176,245 views
- **Structure:**
  - 3-4 viral videos from different niches
  - Reveal they all follow the same pattern
  - "Matrix moment" -- viewer sees underlying structure

### #9. QUICK REFERENCE CARD
- **Avg views:** 80K | **Reels analyzed:** 8
- **Top reel:** 127,000 views
- **Structure:**
  - Visual matrix or categorization system
  - Screenshot-worthy, designed to be saved

### #10. STEP-BY-STEP TUTORIAL
- **Avg views:** 81K | **Reels analyzed:** 12
- **Top reel:** 165,751 views
- **Structure:**
  - Numbered steps to achieve specific outcome
  - Often includes screen recordings

## VISUAL FORMATS (Screenshot Analysis of 100 Reels)

### Format 1: NEON GREEN TEXT + OUTDOOR BALCONY
- Ava on wooden balcony/deck with trees behind
- NEON GREEN (#7FFF00) headline text at top ("SOUND EFFECTS 101", "VISUAL HOOKS 101", "3 VIRAL VIDEOS")
- White subtitle text below
- Micro-mic in hand
- **Used in:** Resource Giveaway, Quick Reference Card, Same Pattern frameworks
- **Performance:** Contains #1 reel (3.3M views)

### Format 2: CLONE / SPLIT SCREEN
- Two Avas side by side (or facing each other)
- Labels for each: "Dumb Person / Smart Person", "Following / Personal Brand", "SLOW Growth / FAST Growth"
- Same clothes but different styling to differentiate characters
- **Used in:** Clone Dialogue, Side-by-Side Comparison frameworks
- **Performance:** Top educational format (267K peak)

### Format 3: SCREEN RECORDING / PHONE MOCKUP
- Instagram profile shown on phone screen
- Green text overlay with metrics/numbers
- **Used in:** Hypothetical Challenge, Case Study frameworks
- **Performance:** 443K views (zero to 10K followers)

### Format 4: LIVING ROOM / COUCH TALKING HEAD
- Ava sitting in gray armchair, cozy living room setting
- Question-format text hook ("What FORMAT goes most viral?")
- Neon green accent text
- **Used in:** Hot Take, Opinion Yap frameworks

### Format 5: CONTENT TYPE MEGA-GRID
- Massive grid showing 20+ content types with thumbnail examples
- Labels under each (Yapping, Storytelling, Educational, Ranking/Rating, etc.)
- Ava talking head at bottom
- **Used in:** Content Type Mega-List framework

### Format 6: PODCAST INTERVIEW CLIP
- Two-person split or single guest talking
- Big metric text ("1M in 6 months")
- Neon green numbers
- **Used in:** Case Study, Hot Take frameworks

### Format 7: VLOG / BTS
- Phone-filmed, raw footage
- "Week in the life of a 21 YEAR OLD Business Owner" text
- Minimal editing, personal moments
- **Used in:** Day-in-the-Life Vlog framework
- **Performance:** Lowest-performing format

## KEY VISUAL BRAND ELEMENTS

- **Brand color:** Neon green (#7FFF00) -- used in every high-performing reel
- **Secondary text:** White for subtitles/descriptions
- **Typography:** Bold, condensed fonts (Impact-style) for headlines
- **Setting insight:** Outdoor settings (balcony) perform better than indoor (living room)
- **Brand marker:** Micro-mic is always visible
