# Instagram без SortFeed: збір через браузер (безкоштовно)

Рішення 2026-10-13: Instagram збирається Claude у Chrome CM (Claude in Chrome) або у вбудованому браузері. Платних сервісів немає. SortFeed лишається запасним варіантом.
Перевірено на examplebrand: сітка Reels дала 32 рілси з переглядами, 9 віральних; посилання отримано відкриттям рілса (найсильніший 126K = `DQUEcXKDmk8`, збігається з research-таблицею команди).

## Кроки для кожного IG-акаунта
1. `navigate` → `https://www.instagram.com/<handle>/reels/`. Якщо Instagram просить вхід → попросити CM залогінитися у своєму Chrome. Не обходити.
2. **Підписники:** з шапки профілю (`Читачі: 14 тис.` / `14K followers`) → число.
3. **Сітка:** `javascript_tool` скролить донизу, доки кількість плиток `a[href*="/reel/"]` не перестане рости (пауза ~1.5 с, до ~25 скролів). Для кожної плитки зчитати текст: перше число = перегляди («20,9 тис.», «126K», «9 688» → число); якщо стоїть оверлей SortFeed, також outlier («4x»). **Посилання з DOM не повертати:** браузерний інструмент їх частково ховає, і це захист, який не обходиться.
4. **Відбір:** віральні = перегляди ≥ 2× підписників. Якщо їх <5, додатково ≥3× медіани плиток (outlier, за рішенням CM).
5. **Посилання лише для відібраних:** для кожної такої плитки клік (`javascript_tool`: `document.querySelectorAll('a[href*="/reel/"')[i].click()`), пауза 2–3 с → URL рілса видно в **Tab Context** результату → записати. Повернутися (`navigate back` або Escape). За потреби з відкритого рілса зчитати лайки й коментарі.
6. Записати `clients/<slug>/work/ig_capture_<handle>.json` (формат у `scripts/ig_capture_to_csv.py`) →
   `python3 -I $CS/cs-content-research/scripts/ig_capture_to_csv.py clients/<slug>/work/ig_capture_<handle>.json clients/<slug>/sources/auto`
7. Оновити підписників в `accounts.csv` (скрипт друкує рядок) → далі звичайний `ingest_sortfeed.py` по `sources/auto`.
8. Закрити свої вкладки.

## Каруселі
Вкладка Posts (`/<handle>/`) → плитки `/p/` → за `carousel_capture.md` (слайди скриншотами, правило віральності каруселей).

## Обмеження
- Instagram показує на сітці лише перегляди; лайки й коментарі — у відкритому рілсі. Saves не видно.
- Дати рілсів видно лише у відкритому рілсі; без них свіжість оцінювати за порядком сітки (нові зверху).
- Акаунт CM використовується для перегляду публічних профілів як звичайний користувач: без масового відкривання (лише віральні), з паузами.
