# Research-бриф (заповнює команда до старту research)

Скіл не визначає нішу, платформи чи конкурентів сам. Він фільтрує контент за цим брифом. Порожнє поле → AI питає Content Manager, а не вгадує.
Файл клієнта: `clients/<slug>/research_brief.md`.

## 1. Клієнт
| Поле | Значення | Джерело (Unpacking, онбординг, CM) |
|---|---|---|
| Ніша | | |
| Акаунт(и) клієнта | IG: @… / TikTok: @… | |
| Платформи для research | Instagram / TikTok / обидві | |
| Основна платформа | | |
| Формати для research | Talking head / BTS / Expert video / Carousel | |
| Client Working Model | Active / Limited / Existing only (з онбордингу) | |
| Період | останні N місяців (за замовчуванням 12) | |
| Теми й обмеження | що не брати (заборонені продукти, claims) | |

## 2. Бриф конкурентів
### 2.1 Назвав клієнт (без додаткового підтвердження, якщо акаунт визначено однозначно)
| Бренд | IG | TikTok | Звідки (таймкод Unpacking / документ) |
|---|---|---|---|

### 2.2 Пропонує AI (тільки після підтвердження CM)
| Акаунт | Платформа | Підписники | Чому релевантний | Рішення CM (yes / no) |
|---|---|---|---|---|

## 3. Критерії відбору
- Віральне = перегляди ≥ 2× підписників акаунта.
- Виняток лише за умовою: якщо в акаунта < 5 таких відео, кандидати ≥ 1× підписників (або ≥ 3× медіани) йдуть до CM з позначкою «виняток».
- Каруселі: лайки (і saves/shares, якщо видно) ≥ 3× медіани каруселей акаунта й помітні відносно підписників. Остаточне «так» за CM.
- Референс підходить за нішею і форматом; самих переглядів недостатньо.
