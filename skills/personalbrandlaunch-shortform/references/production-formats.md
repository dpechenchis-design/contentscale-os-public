# Бібліотека форматів зйомки (Pillar 4: Format)

Джерело: реальні client-facing скрипт-документи іншого агентства (September/October/November
2024 — Scripts & Captions, клієнт — чоловічий mindset-коуч, "Mindful Men Community"). Це НЕ
структура хука/скрипта (те — structure-templates.md), а те, ЯК фізично знято відео. Формат
підказки клієнту, що і як фільмувати — корисно для поля "How to record it" картки-пакета
script-factory.

## Ключ документа (як агентство передає клієнту)
- **Червоний текст** — заповнити (fill-in-the-blank) або важливі нотатки для зйомки.
- **Зелений текст** — інструкції для монтажера (клієнт може ігнорувати).
- **Notes** — розбивка скрипта: тип відео, приклад-референс, інструкції зйомки.
- **Script** — що казати / текст на екрані (примітка клієнту: адаптувати під себе, не
  читати дослівно — "we will never be able to perfectly replicate your words").
- **Caption** — опис під пост. Часто 2 версії CTA: CTA1 (Instagram + ManyChat-автоматизація),
  CTA2 (усі інші платформи, без автоматизації).

## 8 форматів

1. **Audio + Text + Broll** — текст на екрані (Text on Screen) + фонове відео (Background
   Video), без говоріння в камеру. Найпростіший у виконанні.
2. **Multitasking** — говорить у камеру, роблячи паралельну дію (прибирання, готування,
   макіяж). Дія в лівій колонці синхронізована з реплікою скрипта в правій.
3. **Visual/Props** — використання реквізиту, що ілюструє кожен пункт скрипта (папір,
   ручка, магічна паличка) — глядач бачить дію, не тільки чує.
4. **Post-it Note Reveal** — дошка з словами/картинками, закритими стікерами; кожна репліка
   скрипта = зривання одного стікера в той самий момент. Потребує "White Board Layout" —
   заздалегідь підготовлену розкладку слів/картинок.
5. **Talking Head w/ Setting Changes** — говорить у камеру, але сетинг змінюється кожні
   1-2 репліки (зал, з дітьми, кухня) — тримає візуальну динаміку без реквізиту.
6. **Voiceover + Broll Montage** — 2 окремі зйомки: (а) все відео проговорюється сидячи одним
   дублем, (б) окремо знімається брол під кожен пункт; монтажер накладає аудіо (а) на відео (б).
7. **Q&A (Interviewer/Interviewee)** — потрібні дві людини: інтерв'юер задає питання,
   інтерв'юйований відповідає. Природний, менш "скриптований" вигляд.
8. **Viral Video Reaction** — грінскрін-реакція (кивання/хитання головою, жести, без слів) на
   програвання чужого вірального відео з ніші, потім окремо записана репліка з власною думкою.

## Мапінг на Pillar 4
Кожен обраний Structure-скелет (structure-templates.md) потребує СВОГО формату зйомки:
- Handwave / If-X-You-Y → Post-it Note Reveal або Visual/Props (кожен пункт = фізична дія)
- Two-People → потребує двох людей (як Q&A, але без питань — паралельна дія)
- Comparison A-vs-B → Talking Head w/ Setting Changes АБО Visual/Props (два скріни поруч)
- Hypothetical-Challenge → Talking Head (пряма мова) або Voiceover + Broll Montage
- Picture+Name → Audio + Text + Broll (найближчий формат)
