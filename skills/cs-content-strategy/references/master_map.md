## Conventions

- Placeholders are `{{UPPER_SNAKE}}`. Global keys used across pages: `{{CLIENT_NAME}}`, `{{PLATFORM_1_NAME}}` (primary short-form platform, the client = TikTok), `{{PLATFORM_2_NAME}}` (the client = Instagram), `{{PLATFORM_3_NAME}}` (next-phase platform, the client = YouTube).
- Image slots are neutral rectangles (fill `#E9E6E0`) with a grey centred label `{{IMAGE: ...}}` / `{{EMBED: ...}}` sitting on top. To fill a slot: delete the label + rectangle and insert the client image at the same position/size (positions listed below).
- Headings were rewritten as literal UPPERCASE text so the font no longer renders the Turkish dotted "İ" (the original headings were lowercase text shown through an uppercase style).
- List placeholders keep their bullet level; each bullet = one placeholder. To add/remove bullets, add/remove lines in the same text element.
- **Capacity** = approx. max characters per placeholder before the text wraps more than the original layout allows (estimated from box width / font size, ~0.55 x font-size per character for Poppins, and the original the client text length). Counts are per placeholder unless noted.
- **Editing gotcha for the filler (Canva MCP):** `find_and_replace_text` replaces **all** matches in the element, and replacement text inherits the formatting of the character before it. When a placeholder sits directly after a bold label/heading (e.g. first bullet after a bold sub-heading, text after "Goal: "), replacing the whole placeholder can turn it bold. Safe pattern: replace only `{{KEY}}` minus its first `{` with the content prefixed by one throwaway char, then delete that char — or replace `KEY}}` (inside the braces) and then delete the remaining `{{`. Simpler alternative: replace placeholder text inside its own line only, never across a bold/normal boundary.
