## ⚠️ ДЖЕРЕЛО ДАНИХ — жорстке правило

Усі каруселей для роботи беруться **ТІЛЬКИ з бази цього скіла**. Інших джерел немає.

- `references/reels-database.md` — 19 каруселей @sharransrivatsaa: посилання, дата, лайки, коменти, caption і **дослівний текст кожного слайду**. Відсортовано за лайками.
- `references/reels-table.xlsx` — оригінальна таблиця (ті самі дані; картинки винесені в `visuals/`, щоб скіл важив мало).
- Скрінів у таблиці немає: для каруселей формат = текст слайдів, він повністю в базі.

Правила:
1. Посилання, метрика, транскрипт — **копіюються з бази дослівно**. Не округлювати (4,549,912, не «4.5M»), не переказувати, не скорочувати транскрипт — ліва колонка ресогу = ВЕСЬ транскрипт, біт за бітом.
2. Не скрейпити і не шукати рілси інструментами (vidIQ тощо), не брати приклади «з пам'яті» — поки у базі є потрібне.
3. `BTS` / порожній транскрипт / пісня / не англійською = без мови креатора → для 1:1 ресогу не годиться (хіба скелет повністю в тексті на екрані — тоді дивись скрін).
4. Метрика — на дату вивантаження таблиці; у доці так і підписувати.
5. `references/viral-frameworks.md` / `framework.md` — для назв фреймворків і розуміння скелетів, **не** як джерело оригінального тексту.

## 4 Narrative Arcs

### ARC A: Story → Lesson → Framework (SIGNATURE, 7-9 слайдів)
Конкретна історія → crisis → lesson → actionable framework. Найвищий engagement.

```
1. HOOK — Contrarian claim + story teaser + "here's what no one tells you"
2. STORY SETUP — Хто, що, ситуація ДО кризи
3. STORY CRISIS — Момент коли все змінилось
4. LESSON — Що більшість роблять неправильно (bold one-liner)
5-7. FRAMEWORK — Кожен слайд = один принцип/правило з поясненням
8. TAKEAWAY — Summary (✅/❌ format або bold closer)
9. CTA — Comment "[KEYWORD]"
```

**Приклад (26,814 likes):**
Hook: "An LLC won't protect you. My friend lost his house."
Story: Pool company → lawsuit → pierced veil
Lesson: "Creating an LLC is paperwork. Keeping its protection is behavior."
Framework: Separate accounts, documentation, signing correctly
Takeaway: "✅ Filing creates an LLC. ❌ Filing alone doesn't create protection."

### ARC B: Reframe → Named Frameworks (7-8 слайдів)
Проблему більшість фреймить неправильно → правильний діагноз → набір Named Frameworks.

```
1. HOOK — Contrarian reframe ("X ≠ Y. X = Z.")
2. DIAGNOSIS — Називає проблему правильно
3. BRIDGE — Ситуація читача + promise
4-6. NAMED FRAMEWORKS — Кожен має ВЛАСНУ НАЗВУ + story/analogy + bold takeaway
7. CTA
```

**Приклад (2,721 likes):**
Hook: "Burnout ≠ working too hard. Burnout = working hard without seeing results."
Diagnosis: "They are both design problems."
Frameworks: "Run Your Life in Sprints" → "The Buffer Principle (80% Rule)" → "The Friday Review + Preview"

### ARC C: Deal / Case Study Breakdown (6-7 слайдів)
Розбір конкретної угоди/стратегії відомої людини/компанії.

```
1. HOOK — Bold claim (celebrity/brand name + surprising move)
2. CONTEXT — Що більшість не знають
3-5. LAYERS — Кожен слайд = нумерований рівень угоди
6. SYNTHESIS — Ширша lesson
7. CTA (optional)
```

**Приклад (7,701 likes):**
Hook: "In 2023, Messi made a multi-billion dollar bet on himself."
Layers: 1. Inter Miami ($20M + ownership), 2. MLS (Apple TV), 3. Apple TV (subscriber cut), 4. Adidas (merchandise revenue share)
Synthesis: "Every layer relied on the attention Messi brings."

### ARC D: Timeline Identity Transformation (6 слайдів)
Past identity → struggle → present identity → closer. Personal brand building.

```
1. PAST — "This is a boy who..." + bullet list of struggles
2. PAST — More struggle details
3. PRESENT — "This is a man who..." + bullet list of achievements
4. PRESENT — More achievements
5. BRIDGE — "If I could go back..."
6. CLOSER — Bold lesson about identity/perseverance
```

**Приклад (7,885 likes):**
Past: "Left India at 18. Spoke barely any English. Ate from dumpsters."
Present: "President of REAL (NASDAQ: REAX). World-leading podcast."
Closer: "Your challenges don't define you. What you choose to do with them does."

## Named Framework Convention

Головна текстова відмінність Sharran від інших creators.
Кожен numbered item отримує ВЛАСНУ НАЗВУ замість "Tip #1":

| Generic | Sharran's Named Framework |
|---------|--------------------------|
| Tip #1 | **"The Buffer Principle (The 80% Rule)"** |
| Step #2 | **"The Friday Review + Preview"** |
| Shortcut #1 | **"Pay for Access"** |
| Shortcut #2 | **"The 80/20 AI Method"** |
| Problem #1 | **"The Quiet Entrepreneur Trap"** |
| Solution | **"The 9-word email"** |

**Чому працює:** Назви = quotable, shareable, memorable. Люди шерять "The Buffer Principle" в коментарях, не "his tip #2".

## Slide Text Structure

```

Кожне на новому рядку.
Як сценарій фільму.

"He filed the paperwork."

```

### Framework Slides (ARC A slides 5-7, ARC B slides 4-6)
```
# Named Framework Title        ← bold header

Personal story or analogy       ← 1-2 абзаци
that makes the concept real.
Конкретний приклад.

**Key insight in bold.**        ← takeaway

@SHARRANSRIVATSAA               ← branding (optional)
```

### Takeaway Slide
```
✅ Filing creates an LLC.
❌ Filing alone doesn't create protection.
```
або bold one-liner: **"Being coachable beats being cocky."**

### Bold Highlight Strategy
Замість gold кольору — **bold text** для ключових фраз:
- **"Next sprint."** — framework takeaway
- **"coachable, not cocky"** — story lesson
- **"Spoiler: They won't."** — personality/sass moment

## Topical Keyword CTA System

Кожен пост = УНІКАЛЬНИЙ keyword, прив'язаний до теми.

### CTA Formula
```
Comment "[KEYWORD]" and I'll send you [specific deliverable].
```

### Keyword Selection Rules
1. Keyword = topical mnemonic (LLC для LLC, ORANGE для тарифів, RATE для ставок)
2. Короткий, 2-6 символів
3. Пов'язаний з темою поста, не generic
4. Deliverable = newsletter, playbook, article, checklist, link

### Performance Insight
Topical keywords генерують comment rate до 223% (comments > likes).
Generic keyword (як PROTOCOL у coldture) = нижчий comment rate, але вищий brand recall.

## How to Use This Skill

### 1. Write carousel slide text
1. Обери **narrative arc** (A/B/C/D) based on content type
2. Обери **hook template** (H1-H9)
3. Для ARC A: знайди або створи конкретну ІСТОРІЮ з crisis
4. Для ARC B: назви кожен framework (не просто "#1")
5. Для ARC C: розбий угоду на пронумеровані layers
6. Для ARC D: past vs present identity
7. Пиши story slides як сценарій (коротке речення = новий рядок)
8. Bold highlights на key insights
9. Takeaway slide: ✅/❌ або bold one-liner
10. CTA: обери TOPICAL keyword + конкретний deliverable

### 2. Choose arc by content type
| Content | Best Arc |
|---------|----------|
| Є конкретна історія з lesson | ARC A: Story→Lesson→Framework |
| Проблема яку фреймять неправильно | ARC B: Reframe→Named Frameworks |
| Розбір чужої угоди/стратегії | ARC C: Deal Breakdown |
| Personal brand / "who I am" | ARC D: Timeline Identity |
| Короткий punchy insight | 2-Slide Observation |

## Режим: 1:1 Carousel Reskin (два стовпці)

### Процес
1. Взяти карусель з `references/reels-database.md`: посилання, лайки, коменти і ДОСЛІВНИЙ текст кожного слайду звідти.
2. Визначити arc type (A/B/C/D) і розбити скелет по слайдах.
3. Переписати слайд-в-слайд, підставляючи змінні під клієнта.
4. Named Frameworks = нові назви під нішу клієнта.
5. Story = реальна історія клієнта або його клієнта (не вигадувати).
6. Keyword CTA = топікальний для нової теми.

```

**Likes:** X | **Comments:** X | **Arc Type:** A/B/C/D

| ОРИГІНАЛ (слайд) | РЕСКОГ ПІД [клієнт/ніша] |
```
